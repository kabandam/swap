# CRECCOM SWAP Scanner

Mobile-first tablet warehouse scanner for CRECCOM.

## Core features
- Serial-number-first OCR scanning (`S/N:` recognition)
- QR fallback
- Find Device lookup
- Device Sorting sessions
- Duplicate detection within a sorting session
- Supabase backend
- Netlify deployment

## Backend
Supabase project: SWAP Project

## Deployment
Netlify project: swap-yuyf
Target custom domain: swap.creccommw.org

## Files
- `index.html` — application UI and scanner logic
- `netlify.toml` — Netlify configuration
